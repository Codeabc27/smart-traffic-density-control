PROJECT

About the system

Transparent AI-assisted traffic management for a four-way intersection.

WORKFLOW

From video to adaptive signal

Traffic Video→YOLO Detection→Vehicle Count→Density→Signal Optimization→Results

The system processes a traffic video locally, detects configurable vehicle classes, assigns detections to four approach regions, estimates traffic demand and queue occupancy, then selects signal phases using deterministic adaptive rules.

Adaptive timing
